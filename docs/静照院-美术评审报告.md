## 0. 结论先行

**总体分档：小改～局部重做（不动架构）。** 水墨远山、进场卷轴、求签卷轴、HUD 卡片已达到「能留住人」的水准；但**5 个破功资产**（佛像形体、撸猫面板的猫、投币面板的金蟾+水面、落叶堆、挂单僧 icon）会让用户在第一次互动时就「出戏」，**手机端面板洗白全屏**则把氛围直接清零。以下按 P0（破功，必须改）/ P1（拉低质感）/ P2（打磨项）三级列出。

**一句话策略：这个产品要「仅凭美术留住用户」，留住人的不是单件资产的精度，而是「色调统一 + 光随时间变 + 每次点击都有可感知的回应」这三件事。当前最缺的是后两件。**

## 2. P0 · 破功资产清单（用户第一次碰到就会出戏）

### P0-1 殿内主佛「发光肉团」
- **问题**：大佛是一个过曝的白色圆润体，无五官、无手印、无衣纹，靠光晕撑存在感；缩小看像米其林娃娃。
- **为什么是问题**：它是全院构图的正中心、所有视线的落点，也是「礼拜」交互的对象——主佛不可读，禅意空间就没有「佛」。
- **改成什么样**：三选一（按成本升序）① 在现有 GLB 上压 emissive（≤0.15）并把佛前点光从 2.4 降到 1.6，让形体先于光晕被看见；② 用 `renderPropSprite()` 给佛拍一张带明暗的特写，替换殿内平面立绘；③ 重导 `buddha.glb`：螺髻、眉眼凹刻、禅定印、衣褶三段式（预算 8k tri 内，`blender/gen_*.py` 现成管线）。

### P0-2 撸猫面板的「猫」完全不可读
- **问题**：面板中的猫=白色圆球头+两个棕色尖角（读成恶魔角）+两截断开的白爪；毛色参数（橘 #E0922F）未生效，与院子里那只纸片橘猫**完全不同族**。
- **改成什么样**：直接复用 `Monk2D`/`Cat2D` 的 canvas 纸片绘制（那只橘猫造型是对的），把面板渲染改为「同源 2D 特写 + 呼噜波纹」，删除现有 CSS 猫。同族性问题一次解决，零新资产。

### P0-3 投币面板：金蟾悬空 + 水面是「果冻柱」
- **问题**：金蟾呈棕陶色（不金）、悬空浮在水面上方无支撑；水面在桌面端是一个半透明圆柱体、手机端是玻璃碟——都不是「水面」；池底硬币是白球团。
- **改成什么样**：① 金蟾换 `toad_v2.glb` 金色系材质（metalness 0.25 / roughness 0.6 / 旧金 #B49A68），面板里给它脚下加一块池心石；② 水面改为俯视平面椭圆（渐变+两笔涟漪弧线），去掉 3D 体块感；③ 硬币用 `coin.glb` 同源渲染或 canvas 方孔钱俯视图。重排构图：蟾占上 1/3，水面占下 2/3。

### P0-4 落叶堆 = 香蕉皮
- **问题**：叶片是大块弯月形黄色体块+棕色圆环底座，缩小看是「香蕉+游泳圈」。
- **改成什么样**：叶片改三笔画的小叶形（菱形/椭圆+叶柄一笔），单叶 ≤0.15 单位；去掉圆环底座，改为 5–8 片叶围着一点自然散落；颜色从明黄降到旧金 #B49A68 偏枯。扫描后飞散时叶子变小片旋转下落即可。

### P0-5 挂单僧 / 观赏树 / 擦佛 三块面板是「另一个游戏」的 icon
- **问题**：挂单僧=黑帽绿口袋图标；观赏树=三个圆+一根棍；擦佛=姜黄雪人。它们是纯 CSS 几何拼的，与水墨+纸片风格完全脱族。
- **改成什么样**：统一走「同源渲染」管线（项目已有 `renderPropSprite()`，给 9 个旧面板用过）：挂单僧用 `Monk2D` 纸片僧立绘；观赏树用场景里那棵松的 3D 特写渲染图（有真实姿态和块面叶）；擦佛用 `buddha.glb` 特写 + 尘埃层叠加。**规则：面板内出现的一切形象必须是场景中已存在形象的同源图，不再手绘 CSS 几何。**

## 3. P1 · 拉低质感（第二次体验就会注意到）

| # | 问题 → 为什么 → 改成什么样 |
|---|---|
| P1-1 | **手机端面板遮罩把场景洗成纯白**（m-scene/m-coin 实测场景几乎不可见）→ 面板一开，空间感与氛围归零，这是移动端留存的最大杀手 → 遮罩不透明度从当前 ≈0.75 降到 0.25–0.3，仅保留面板本体的宣纸底；让「打开面板还能看见自己在哪」 |
| P1-2 | **柱子/灯笼朱砂红饱和度失控** → 大红柱+橙红发光灯笼把「清雅禅院」推向「公园仿古建」，是色谱里唯一超纲的元素 → 柱色降为 #96574C（低饱和朱砂）并向墨青压 10% 明度；灯笼自发光降一半，白天只留纸灯笼的米黄面 |
| P1-3 | **蒲团=石磨盘** → 灰绿扁圆+白色虚线圆环没有布的语义 → 每张蒲团加：布纹程序化 bump、外圈一圈缝线（实线短划）、中心小凹（坐痕）、三档色差保留；厚度再抬高 20% |
| P1-4 | **跪拜剪影不可读** → 跪下后纸片僧是一条白色细条（俯身姿势从头到脚叠成一线）→ 跪拜 pose 改侧身 45° 俯身（剪影有起伏），或跪拜时切「侧面视角纸片」专用帧 |
| P1-5 | **小物件点击热区与引导**（真人实测连续点空 4 次：拜垫 hitbox 吞掉签筒/金蟾）→ 新用户不知道什么能点、点不中就流失 → ① 所有可交互物 hitbox 最小 1.2 单位且互不遮挡（拜垫 hitbox 缩小到本体）；② hover 时物件放大 5% + 名字气泡常显；③ 靠近 2 步内，可交互物脚下柔光圈呼吸频率加倍——用光圈当「该点我」的信号 |
| P1-6 | **提示文字对比度过低**（「摇一签」「点香筒·就烛·插炉」「轻轻顺毛」浅金 on 浅米，截图里几乎不可读）→ 全部改墨青 #2E3532 或朱砂，字号 +2px |
| P1-7 | **碑刻 3D 本体是素色纸盒** → 院门南侧石碑无碑文、无风化 → 3D 碑面用 `plaqueTexture()` 竖排刻「山静似太古/日长如小年」，基座加青苔色斑；面板里碑形改竖碑（现在是横卷，语义不对） |
| P1-8 | **木鱼/念珠面板物件裸浮** → 物体悬在真空，没有投影和台座 → 每个面板统一加「台座 + 接触阴影 + 背景一炷淡烟」，一个 30 行的公共 CSS 类即可，全部面板受益 |

## 4. P2 · 打磨项（第三眼与长期）

- 地砖接缝重复感重（26×26 平铺）→ 换 2 张交替 tile 或 UV 随机翻转。
- 石灯过细，夜间没有点亮状态 → 灯箱加暖光自发光（黄昏后自动亮，配合 P2-晨昏）。
- 香筒像笔筒、蜡烛是西式奶白柱 → 香筒加竹节线；蜡烛改红烛（朱砂低饱和）或改油灯。
- 御道与地面对比弱 → 御道石板换大 1.5 倍规格+深一档。
- 香炉烟几乎不可见 → 烟 sprite 拉长变淡（透明度 0.25、高度 1.5→2.2）。
- 纸片小沙弥存在感弱 → 脚下柔光圈改常显（不只是 hover），影子加深 0.28→0.4。

## 5. 交互优化方向（用户视角实测后的建议）

按「凭美术留人」的目标排序，前两条是杠杆最大的：

1. **让场景本身随时间变**（最大杠杆）。现在「晨昏叶色」只写进了观赏树面板的文字里，场景光照是恒定的晨光。把时段做进 3D：清晨冷青+长影 → 正午通透 → 黄昏旧金+灯笼自动点亮 → 夜晚墨青+佛前灯成为唯一光源。**同一个空间每天打开都不一样，这是「没有玩法也能留住人」的核心机制**——回访的理由不用靠数值，靠「我想看看傍晚的院子」。
2. **面板即空间，不是弹窗**。现在开面板=场景消失（桌面洗白 55%、手机≈90%）。改成「聚焦卡贴着物件弹出 + 场景保持可见 + 相机轻推向该物件」，用户始终知道自己站在院子里。求签卷轴已经是对的形态，把其他面板向它看齐。
3. **点击反馈闭环**。实测点空 4 次说明「点哪都行」变成了「点哪都不确定」。三件套：hover 名牌常显、可点物呼吸光圈、点击落空时给一个极淡的水墨涟漪（告诉用户「这里点不了」，而不是没反应）。
4. **首次进庙的 60 秒引导**。进场卷轴后，用挂单僧的气泡按顺序送 3 句话：「签筒在月台边，求一签看看」「树在东南角，可以系条飘带」「佛前可以跪一跪」——用户视角下，现在的触点全靠discover，第一次来的人 2 分钟内碰不到签文就走了。
5. **动作的世界内演出优先**。v57 已把木鱼/念珠/上香改到小沙弥身上演（方向完全正确）；建议投币、擦佛也回到世界内（金蟾张口吞币的动画 > 面板里点水面），面板只保留需要输入的：求签、愿灯、碑刻。
6. **声音分层**。环境底噪（风/水/鸟）随晨昏换，动作音效已有——但所有面板共用一个念经底噪，求签时换成风铃+木鱼远声，氛围立刻贵一档。

## 7. 假设与边界

- 假设：保留现有「无主玩法、氛围观赏」定位（待确认——若要主玩法，晨昏系统的优先级会变）。
- 假设：图像生成额度仍受限（≤2 张），故 P0 全部走「同源渲染/程序化改造」路线，不引入新 AI 图。
- 佛像重导属 3D 资产工作，本轮报告只给规格方向；面数预算 8k tri / 无骨骼。
- 未实测：真实 GPU 帧率下的后处理表现、iOS Safari 的 CSS 遮罩性能。
